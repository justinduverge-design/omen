# Omen logos

The live logo set. The mark is **Omen B2**, an aged-brass letter **O** whose inner space is an American
football.

| Path | What it holds |
|---|---|
| `svg/` | **Vector masters.** The symbol in each colourway, the wordmark, horizontal and stacked lockups, micro sizes and the app icon master. Edit these, never the PNGs |
| `*.png` | Rasters rendered from the masters: favicons (16-512), the app icon (1024), the maskable icon, the emblem, the wordmark and the lockups |
| `textures/` | Reserved for chant texture masks. Empty |

Figma is the source of truth for vector assets (facts-of-record #20). Usage rules (clear space, colour on dark
or light) are in `Brand/brand-system.md`.
