# ADR-004: Replace passport-yahoo-oauth2 with Axios-Based OAuth

**Date:** 2026-05-12
**Status:** Accepted (Implemented)
**Deciders:** Justin Duverge (CEO/Founder), Claude (Architect)

## Context

The `passport-yahoo-oauth2` package depended on the `request` npm package, which was deprecated in 2020 and carried a persistent security vulnerability chain. The npm audit gate failed as long as this dependency was present. Yahoo OAuth 2.0 is well-specified and can be implemented directly with `axios` without a wrapper package.

## Decision

Remove `passport-yahoo-oauth2` and all `request`-chain dependencies. Implement Yahoo OAuth 2.0 directly in `src/services/yahooAuth.js` using `axios`. This cleared the npm audit gate to 0 findings.

## Consequences

**Positive:**
- npm audit gate passes (0 findings)
- 48 packages removed from the dependency tree
- Full control over the OAuth flow and error handling
- No dependency on an unmaintained package

**Negative / Trade-offs:**
- Yahoo OAuth flow now requires maintenance if Yahoo changes their API
- More code owned internally vs. delegated to a package

**Constraints:**
- The `request` package and its chain must not be re-added in any form
- Any new OAuth library must pass npm audit before adoption
