# Pre-DBS Handoff Contract Notes

This note indexes the old root-level `handoffs/` folder before it was archived into `Archive/handoffs-pre-dbs/`.

## Useful Historical Material

- `backend-to-frontend.md` contains a large historical contract library for Draft Assistant ADP, Omen of the Week, Platform Status, Start/Sit, Waiver Wire, and live Omen behavior.
- `frontend-to-backend.md` contains the older frontend request queue and Phase 4/5 frontend-backend integration notes.
- `decisions.md` contains session history from May 17-18, 2026, including early Omen, backbone endpoint, and platform-state decisions.
- `decision_log.md` contains older product and technical decisions that are mostly superseded by `Direction/decision_log.md` and `Blueprints/handoffs/decisions.md`.

## Canonical Current Locations

- Active frontend-to-backend requests: `Blueprints/handoffs/frontend-to-backend.md`
- Active backend-to-frontend contracts: `Blueprints/handoffs/backend-to-frontend.md`
- Active shared engineering decisions: `Blueprints/handoffs/decisions.md`
- App/repo decision log: `Direction/decision_log.md`

## Usage Rule

Treat archived pre-DBS handoff files as reference material only. Do not resume writing to root-level `handoffs/`.
