# Corvus Blueprints

This folder holds Corvus product blueprints.

Use it for product handoffs, prompts, specs, playbooks, skills, and implementation-adjacent planning docs that apply to the Corvus app.

## Key Paths

- `handoffs/` - frontend/backend coordination and shared engineering decisions.
- `prompts/` - Corvus-specific runnable prompts.
- `specs/` - Corvus product, UX, backend, and implementation-neutral specs.
- `playbooks/` - Corvus operational or workflow playbooks.
- `skills/` - product-local skills only when they are Corvus-specific.

Global SLOPS skills live at:

```text
..\..\Blueprints\skills\
```

Division-level blueprints live at:

```text
..\Blueprints\
```
