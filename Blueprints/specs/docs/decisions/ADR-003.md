# ADR-003: Trade Analyzer Always Free

**Date:** 2026-05-17
**Status:** Accepted
**Deciders:** Justin Duverge (CEO/Founder)

## Context

Omen is a paid product (MVP Move). Trade Analyzer is the primary free tool. A free, always-available, auth-free tool serves as the trust-building entry point — users can see Omen's decision quality before committing to a paid plan. This pattern is common in best-in-class SaaS: give away the tool that demonstrates value, gate the tool that delivers continuous advantage.

## Decision

Trade Analyzer is permanently free. No authentication is required. No usage cap applies at launch. It is the flagship free feature for word-of-mouth and trust.

## Consequences

**Positive:**
- Reduces friction for new users evaluating Omen
- Demonstrates the VORP-based decision standard at zero cost
- Creates a shareable, viral product surface
- Separates trust-building from monetization

**Negative / Trade-offs:**
- Free usage may generate API load without revenue offset
- Quality of the free tool must still meet the AAA standard — "free" does not mean unfinished

**Constraints:**
- Trade Analyzer must never be gated behind auth or payment
- A usage cap may be added post-launch only with explicit Justin approval (see roadmap item 16)
