# ADR-002: Remove Ask Slops Permanently

**Date:** 2026-05-17
**Status:** Accepted
**Deciders:** Justin Duverge (CEO/Founder)

## Context

Early versions of Omen included a user-facing chat interface called "Ask Slops." User-facing prompt boxes create the expectation of a general-purpose AI assistant, which conflicts with Omen's identity as a structured decision layer. The chatbot pattern also invites hallucination, undermines trust, and replaces the product interface with an empty prompt.

## Decision

Ask Slops is permanently removed from all user-facing surfaces. The LLM is backend-only. Users do not type prompts to the model. The model narrates deterministic football math and does not drive interface or product logic.

## Consequences

**Positive:**
- Product identity stays clear: Omen is a decision layer, not a chatbot
- Reduces hallucination risk by removing open-ended input
- Interface guides users toward action without requiring prompting
- Simplifies the product surface for launch

**Negative / Trade-offs:**
- Users who expect AI chat cannot access the model directly

**Constraints:**
- No Ask Slops feature may be re-added without a full product decision from Justin
- LLM output must always be framed as structured reasoning, not conversational response
