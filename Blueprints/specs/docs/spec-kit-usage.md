# Spec Kit Usage Notes

This folder is compatible with a manual Spec Kit-style workflow.

You do not need to run implementation commands yet.

Use the specs as source-of-truth files before asking Claude or Codex to build.

## Manual workflow

1. Write/update spec
2. Clarify decisions
3. Create task list
4. Assign to Codex or Claude
5. Require handoff
