# ADR-008: Start/Sit Is Not a Standalone Route

**Date:** 2026-05-17
**Status:** Accepted
**Deciders:** Justin Duverge (CEO/Founder)

## Context

Start/Sit is a lightweight, single-decision tool. Giving it a dedicated top-level route (`/start-sit`) would imply feature parity with MVP Move, fragment the navigation, and create a URL to maintain. The tool is most useful inside the decision dashboard alongside Trade Analyzer and Omen of the Week, where the user can move between tools in one session.

## Decision

Start/Sit lives as a tab inside the Football/Hall of Records dashboard (currently `/football`). It is not a standalone page or top-level route. There is no `/start-sit` URL.

## Consequences

**Positive:**
- Simpler navigation — one entry point for all decision tools
- Users can cross-reference Omen, Trade, and Start/Sit without leaving the page
- Easier to gate behind auth at the page level if needed

**Negative / Trade-offs:**
- Start/Sit is not directly deep-linkable without a hash route
- Cannot share a URL directly to the Start/Sit tool

**Constraints:**
- A `/start-sit` route must not be added without a product decision from Justin
- If the Football page is renamed or split, Start/Sit routing must be explicitly re-decided
